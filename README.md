# GrooLauncher (그루 런처)

현장 엔지니어, IT 관리자, 그리고 실무자를 위한 **무설치(Portable) 통합 유틸리티 런처**입니다.  
별도의 설치 과정 없이 압축을 풀고 `GrooLauncher.exe`만 실행하면 13종의 실무·시스템 도구를 한곳에서 바로 사용할 수 있습니다.

---

## 주요 특징

- **100% 무설치 포터블(Portable):** USB에 담아 폐쇄망·현장 PC에서도 바로 실행 가능
- **OS 아키텍처 자동 판별:** 64비트 / 32비트 환경에 맞는 실행 파일을 자동으로 선택
- **자유로운 순서 편집:** 드래그 앤 드롭으로 자주 쓰는 도구 순서를 변경 (`GrooLauncher_order.json` 저장)
- **카테고리 및 실시간 검색:** GROO 도구 / 시스템·유틸리티 분류 및 키워드 검색 지원
- **기능 제한 없는 무료 배포:** 모든 도구를 기능 제한 없이 무료로 사용할 수 있습니다.

## 실행 방법 및 보안 경고 안내

1. 다운로드한 `.zip` 파일의 압축을 원하는 폴더에 풉니다.
2. `GrooLauncher.exe`를 실행합니다.
   - 개별 프로그램만 필요한 경우 각 프로그램 폴더 내 실행 파일을 직접 실행하거나 개별 배포판을 사용하세요.

### Windows의 PC 보호(SmartScreen) 창이 뜰 경우
개인 개발자 배포 파일 특성상 처음 실행 시 Windows 보안 경고가 표시될 수 있습니다.
1. 경고 창에서 **`추가 정보`** 를 클릭합니다.
2. 아래쪽에 나타나는 **`실행`** 버튼을 클릭하면 정상 실행됩니다.
